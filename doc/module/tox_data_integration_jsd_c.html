Jensen-Shannon-Divergence (JSD) Compatibility Test (gJCT) JSD Calculation

The step that turns neighborhood residuals -- as produced by the preprocessing module -- into a JSD value: residuals are binned into histograms per study, the two distributions are compared per reference point, and the per-point divergences are weighted into one global figure for the pair of studies.


Uses

    • f42_safeguard
    • iso_c_binding
    • tox_errors
