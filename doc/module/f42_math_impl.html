public interface is_close

Tolerance-based approximate equality for real(real64). Called as is_close(a, b) with the machine-epsilon tolerance, or as is_close(a, b, eps) where the caller has its own notion of "the same" -- a domain epsilon such as a smoothing floor, which is coarser than anything the arithmetic itself would justify. See is_close_within.

public interface operator(.isclose.)

Tolerance-based approximate equality operator for real(real64); see is_close_default. An operator takes exactly its two operands, so the custom-tolerance form is reachable only by calling is_close directly.
