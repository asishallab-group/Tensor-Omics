k-d tree spatial index over fixed-dimensional point sets. Builds a k-d tree by recursively partitioning kd_indices around the median point along a caller-supplied, cycling dimension order, using a stack-based (non-recursive) traversal so it is safe to call from pure procedures. The tree is stored implicitly as an in-place-permuted index array rather than as linked nodes.
