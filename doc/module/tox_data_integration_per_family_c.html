Jensen-Shannon-Divergence (JSD) Compatibility Test (gJCT) JSD Calculation per family

The JSD value for a sub-neighborhood -- typically the genes of one family -- obtained by driving the same pipeline over a masked set of neighbors. Answers whether two studies are compatible for this family, which the global figure can hide either way.


Uses

    • f42_safeguard
    • iso_c_binding
    • tox_errors
