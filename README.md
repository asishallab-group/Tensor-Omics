# Protein Function Prediction
This folder contains all methods and results of the Protein Function Prediction. All materials, methods and results are available
on the Bioserver under `/media/BioNAS2/Tensor_Omics/Protein_Function_Prediction`. All scripts were executed on the Bioserver.

# Folder structure
Protein_Function_Prediction/
|-methods/                    # contains all scripts and logs from executions
|-material/                   # contains parts of the material, some files are too big for this repository
|-results/                    # contains all results
  |- results_binary/          # contains all single results of the binary approach
  |- results_tf-idf/          # contains all single results of the tf-idf approach

# Availability
Please check `media/BioNAS2/Tensor_Omics/Protein_Function_Prediction/README.md` for more details on all scripts.
